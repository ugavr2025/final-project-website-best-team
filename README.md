## Project Description
A mixed-reality learning lab for Meta Quest that lets students see, touch, and debug core data structures and algorithms in their own space. Build and manipulate arrays, linked lists, stacks/queues, trees/heaps, and graphs as 3D holograms; then step through sorting, searching, and traversal routines with live pointer updates, operation counters, and time/space complexity overlays.
